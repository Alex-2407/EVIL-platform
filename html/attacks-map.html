Che significa «cache o fallback etichettato»?

Feed live — EVIL interroga in tempo reale le API pubbliche (CISA KEV, NIST NVD, CERT Italia/Europa) e aggiorna mappa e statistiche.

Cache — Se le API esterne non rispondono o sono lente, il server mostra l’ultimo snapshot salvato su disco (con data/ora visibile in «Aggiornato»). I dati restano utili ma non sono istantanei.

Fallback / demo — Se non c’è né live né cache valida, EVIL mostra un dataset dimostrativo etichettato nel badge arancione («Dati demo — feed offline»), così la mappa non resta vuota in didattica.
