Profilazione da Social Network

Correlazione passiva di username su piattaforme note: API pubbliche (GitHub, Reddit) e link verificabili. Nessun dato inventato — solo ciò che le fonti restituiscono. Opzionale: email per controllo breach (HIBP).

10 piattaforme · GitHub API · Reddit JSON — ~5–15 s — accesso libero (temporaneo)

Etica: non effettua login n— scraping aggressivo. I check HTTP sui social sono indicativi: conferma sempre manualmente prima di trarre conclusioni in un contesto reale.
