🧪 Lab Virtuale

Ambienti virtuali isolati per praticare tecniche di sicurezza con istruzioni passo-passo.

🔍 Lab 1: Network Reconnaissance

Livello: Principiante | ⏱️ 2-3 ore | ⭐⭐☆

Mappa la rete usando nmap, ping, traceroute. Scopri host e servizi attivi.

🎯 Lab 2: Vulnerability Scanning

Livello: Intermedio | ⏱️ 3-4 ore | ⭐⭐⭐

Usa OpenVAS/Nessus. Identifica e classifica vulnerabilità secondo CVSS.

💻 Lab 3: Web Application Testing

Livello: Intermedio | ⏱️ 4-5 ore | ⭐⭐⭐

SQL injection, XSS, CSRF. Usa Burp Suite per intercettare traffic.

🔑 Lab 4: Password Attacks

Livello: Intermedio-Avanzato | ⏱️ 3-4 ore | ⭐⭐⭐⭐

Dictionary attacks, brute force. Usa hydra, hashcat, John the Ripper.

🔓 Lab 5: Privilege Escalation

Livello: Avanzato | ⏱️ 4-6 ore | ⭐⭐⭐⭐

Escalare privilegi. Exploit kernel, sudo abuse, binary SUID.

🎖️ Lab 6: Full Penetration Test

Livello: Esperto | ⏱️ 8-10 ore | ⭐⭐⭐⭐⭐

End-to-end: recon, scanning, exploitation, post-exploitation, reporting.
