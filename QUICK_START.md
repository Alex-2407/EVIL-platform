# 🚀 QUICK START - Sistema di Progressi EVIL

## 📋 In 2 Minuti

### Step 1: Avvia il Server
```bash
npm start
# o
node server.js
```

Server online su `http://localhost:5000`

### Step 2: Registrati
1. Vai a `http://localhost:5000/account.html`
2. Riempi il form
3. Clicca "Registrati"

### Step 3: Accedi
1. Vai a `http://localhost:5000/login.html`
2. Inserisci le credenziali
3. Clicca "Accedi"

### Step 4: Visualizza Profilo
- Clicca su "👤 Profilo" nel menu
- O vai a `http://localhost:5000/profile.html`

### Step 5: Sblocca Trofei
Esegui queste attività:

| Trofeo | Attività | Link |
|--------|----------|------|
| 🔍 Primo Scan | Fai 1 scansione | `/security-check.html` |
| 🎣 Phishing Defender | Quiz 100% | `/phishing-quiz.html` |
| 🌐 Master DNS | 10 enumerazioni | `/dns-enumerator.html` |
| 🔒 Analista SSL | 5 analisi | `/ssl-analyzer.html` |
| 🦠 Esperto Malware | 5 identificazioni | `/malware-classification.html` |

## ❓ Domande Comuni

**Q: Dove posso vedere i miei progressi?**
A: Nel profilo (`/profile.html`). Vedrai tutte le statistiche e i trofei.

**Q: L'animazione non appare?**
A: 
- Assicurati di essere loggato
- Controlla che il browser non sia in mute
- Prova a ricaricare la pagina

**Q: Posso perdere i progressi?**
A: No! Sono salvati nel server. Accedi di nuovo e li troverai.

**Q: Quanto tempo rimane l'animazione?**
A: 4 secondi. Poi scompare automaticamente.

**Q: Quali sono i trofei più facili?**
A: Primo Scan, Analista SSL, Monitore Attacchi (solo 1 attività).
